# R003 Enumerate deliverables, map each to an inspected artifact

- **Status:** hypothesis (provisional in skill v0)
- **Applies when:** always, especially for multi-part requests.
- **Action:** at intake, list every required deliverable with its acceptance check. Before completion, map each one to an artifact that exists, opens and was inspected.
- **Evidence:** 1 case (lineage `yacht-c`, details in the private case archive). Exterior concepts plus a plan for every deck were requested. The retro records the exterior board but no evidence that the deck plans were delivered or inspected. This shows a completion-evidence gap, not proof that the plans never existed.
- **Exceptions / counterexamples:** none recorded yet.
- **Verify by:** every mandatory deliverable passes its checklist. A missing plan or editable file fails the run even if the hero render looks good.
