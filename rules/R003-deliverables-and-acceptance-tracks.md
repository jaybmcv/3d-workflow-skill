# R003 List deliverables up front; evidence each acceptance track separately

- **Status:** supported (6 project families)
- **Applies when:** Always, especially multi-part requests and anything called "game ready".
- **Action:** List every deliverable at intake. Before saying done, map each one to an artifact that exists and was inspected, and report visual, technical, runtime and release tracks separately.
- **Evidence:**
  - Large spacecraft: exports reported 0 errors before the user said "all janky".
  - Procedural island scene: an all-4/5 self-score was followed by more user complaints.
  - Walkable cargo spaceship: repeated "verified" and "published" summaries, then the user found more defects.
  - Six-deck superyacht: "visual fidelity remains unfinished" alongside passing technical checks.
  - Small spacecraft and motorcycle: technical checks passed while visual acceptance was never recorded.
- **Exceptions / counterexamples:** None recorded.
- **Verify by:** Every mandatory deliverable maps to an inspected artifact; each track is reported on its own.
