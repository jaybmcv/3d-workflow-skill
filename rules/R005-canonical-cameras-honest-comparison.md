# R005 Agree canonical comparison cameras; compare honestly

- **Status:** supported (4 project families)
- **Applies when:** Matching a reference.
- **Action:** Define comparison cameras matching each reference view and confirm them with the user. Compare only against frozen external references. Do not score against images rendered from the model, and do not claim fidelity percentages without an agreed method.
- **Evidence:**
  - Large spacecraft (user verdict): issues "comparing to the right camera angle" until the user specified default camera angles.
  - Procedural island scene: "make it canonical"; later the agent admitted "render-derived images created circular fidelity comparisons".
  - Six-deck superyacht: 53 status updates mentioned a 90% target that was never verified.
  - Small spacecraft: "go to 99% visual fidelity" with no measurement method.
- **Exceptions / counterexamples:** None recorded.
- **Verify by:** Comparison images use the confirmed cameras; no self-referential scores; remaining differences are listed.
