# R010 Keep a decision log in the project

- **Status:** hypothesis (6 project families)
- **Applies when:** Any project likely to run longer than one session.
- **Action:** Record references and priority, canonical cameras, intake answers, budgets and accepted milestones in a file in the project, and update it at each milestone.
- **Evidence:**
  - About six of the 13 retrospectives lost the early modeling history to context compaction, including both projects that took 12 to 13 hours (motorcycle, sports car). Projects that kept a handoff file recovered more.
- **Exceptions / counterexamples:** Short one-session jobs.
- **Verify by:** A new session can resume from the log without re-asking settled questions.
